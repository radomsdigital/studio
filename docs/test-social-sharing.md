## 🐛 Troubleshooting

### If preview image doesn't show:

1. **Clear cache on social platforms:**
   - Facebook: Use the debugger tool and click "Scrape Again"
   - Twitter: Wait a few minutes, cache updates automatically
   - LinkedIn: Use Post Inspector and click "Inspect" again

2. **Check image accessibility:**
   - Visit: `https://leywok.com/opengraph-image`
   - Image should load directly in browser
   - Check browser console for errors

3. **Verify metadata:**
   - View page source (Ctrl+U / Cmd+Option+U)
   - Search for "og:image"
   - Verify URL is correct and accessible

4. **Test in incognito/private mode:**
   - Some browsers cache aggressively
   - Private mode forces fresh load
